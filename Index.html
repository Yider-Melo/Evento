Cloud

La computación en la nube Cloud es un modelo que permite acceder a recursos tecnológicos como servidores, almacenamiento, bases de datos, redes, software y servicios a través de internet, sin necesidad de contar con infraestructura física propia.

Modelos de entrega y ejemplos

1. IaaS: Este nos proporciona una infraestructura básica en la nube servidores virtuales, redes, almacenamiento y sistemas operativos. Ejemplo: Amazon Web Services (AWS) – EC2 máquinas virtuales bajo demanda.

2. PaaS: Ofrece un entorno de desarrollo listo para usar, con herramientas y servicios para crear probar y desplegar aplicaciones sin preocuparse por la infraestructura. Ejemplo: Google App Engine ejecución de aplicaciones en la nube.

3. SaaS: Proporciona aplicaciones listas para usar a través de internet, el usuario accede al software sin instalarlo ni administrarlo solo lo utiliza. Ejemplo: Gmail correo electrónico en la nube

modelos de despliegue

Nube Pública es la infraestructura es propiedad de un proveedor externo que ofrece servicios de computación (servidores, almacenamiento, bases de datos, etc.) a múltiples clientes a través de Internet. Ejemplo: Una empresa que aloja su aplicación en Azure App Services.

Nube Privada es la infraestructura que es utilizada de manera exclusiva por una sola organización, puede estar gestionada internamente o por un proveedor externo pero el acceso está restringido. Ejemplo: Un banco que implementa su propia nube.

Nube Híbrida es la combinación de la nube pública y privada, permitiendo mover cargas de trabajo entre ambas según necesidades de seguridad costo o escalabilidad. Ejemplo: Una empresa que guarda datos sensibles en una nube privada, pero usa la nube pública para análisis de big data.

Nube Comunitaria es la infraestructura compartida por varias organizaciones con intereses comunes industria, regulaciones, objetivos. Ejemplo: Varias universidades que comparten una nube para proyectos de investigación.

Proveedores

Amazon Web Services (AWS) es líder del mercado, servicios de cómputo, bases de datos, almacenamiento, IA.

Google Cloud Platform (GCP) es la más fuerte en análisis de datos, IA y machine learning.

IBM Cloud tiene el enfoque en soluciones híbridas y empresariales.

Oracle Cloud es especializado en bases de datos y ERP en la nube.

Alibaba Cloud es el líder en Asia, con amplia infraestructura global.

VMware Cloud es muy usado comúnmente en nubes privadas e híbridas.

Vercel

Support Framework

Vercel ofrece soporte de primera clase para una amplia gama de frameworks populares, permitiendo implementar aplicaciones frontend, backend y full-stack con herramientas como Next.js, SvelteKit y Nitro, frecuentemente sin necesidad de configuración previa. La plataforma se integra con proveedores Git para generar URLs de vista previa en cada pull request y proporciona funciones avanzadas como Vercel Functions, Middleware, soporte multi-runtime, Incremental Static Regeneration, análisis de rendimiento con Speed Insights y Analytics, y Skew Protection para prevenir errores de versión.

Getting started

Vercel es una plataforma para desarrolladores que ofrece herramientas, flujos de trabajo e infraestructura para construir e implementar aplicaciones web de manera más rápida y sin necesidad de configuración adicional. Soporta los frameworks frontend más populares y cuenta con una infraestructura escalable y segura distribuida globalmente, lo que permite servir contenido desde centros de datos cercanos a los usuarios para obtener velocidades óptimas. Para comenzar a utilizar Vercel, es necesario crear una cuenta eligiendo el plan adecuado, ya sea iniciando sesión con un proveedor de Git o mediante autenticación por correo electrónico (que puede requerir confirmación tanto de email como de número telefónico). La plataforma proporciona herramientas para colaboración en tiempo real durante el desarrollo, como entornos automáticos de preview y producción, además de comentarios en despliegues de prueba. Aunque muchas instrucciones utilizan el dashboard, también se puede emplear la CLI de Vercel instalándola mediante gestores de paquetes como pnpm, yarn, npm o bun.
